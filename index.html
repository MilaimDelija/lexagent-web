How it works

Add three lines.
Sleep better at night.

LexAgent fits into your existing agent code without refactoring. You wrap the actions that matter — LexAgent does the rest.

1

Install the SDK

One package for Python and JavaScript. Works with LangChain, CrewAI, AutoGPT, or your own custom agent. pip install lexagent and you're ready.

2

Wrap agent actions

Call lex.decision() around any automated decision. LexAgent classifies the legal risk against your chosen frameworks in under a millisecond.

3

Stay compliant, always

Every action gets anchored to the blockchain. Regulator-ready PDF reports generated automatically. Human oversight triggered when the law requires it.

your_agent.py 
# Before LexAgent — invisible risk
def approve_loan(applicant_id, amount):
    return lending.approve(applicant_id, amount)

# After LexAgent — three lines, full coverage
from lexagent import LexAgentSDK
lex = LexAgentSDK(api_key="lxa_...", frameworks=["EU_AI_ACT", "GDPR"])

def approve_loan(applicant_id, amount):
    lex.decision("Approve loan", {"id": applicant_id}, {"amount": amount})
    return lending.approve(applicant_id, amount)
